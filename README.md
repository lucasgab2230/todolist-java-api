# Task Manager - REST API (Spring Boot)

Developed in **Java** with **Spring Boot** to task management (To-Do List), created to backend architecture studies and database.

## Used Stack
* **Java 25**
* **Spring Boot**
* **Spring Web** (to build REST routes/endpoints)
* **Spring Data JPA** (to data persistence)
* **H2 Database** (memory database for tests)
* **Maven** (dependency manager)

## How to run the project

Certify to have the **Java** and **Maven** installed on your Linux environment.

1. Clone the repository:
   ```bash
   git clone [https://github.com/lucasgab2230/todolist-java-api.git](https://github.com/lucasgab2230/todolist-java-api.git)
   ```

2. Enter on project folder:
   ```bash
   cd todolist-java-api
   ```

3. Execute the application using Maven:
   ```bash
   mvn spring-boot:run
   ```

4. The API will run locally in port `8080`.
